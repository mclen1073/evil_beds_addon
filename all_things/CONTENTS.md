# All Things Bundle

This folder contains the complete Bedrock addon package in one place.

## Included
- `Evil+Beds+Datapack-Bedrock/manifest.json`
- `Evil+Beds+Datapack-Bedrock/functions/load.json`
- `Evil+Beds+Datapack-Bedrock/functions/tick.json`
- `Evil+Beds+Datapack-Bedrock/functions/evil_bed/*.mcfunction`
- `Evil+Beds+Datapack-Bedrock/functions/evil_beds_addon/*.mcfunction`

## Use
Copy `all_things/Evil+Beds+Datapack-Bedrock` to your Minecraft Bedrock `behavior_packs` folder.
